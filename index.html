☁️ Google Sheets 클라우드 DB 3분 설치 가이드

  1. 구글 드라이브에서 새 Google 스프레드시트를 만듭니다.
  2. 상단 메뉴 [확장 프로그램] → [Apps Script]를 엽니다.
  3. 기존 코드를 지우고 아래 버튼으로 복사한 통합 동기화 스크립트(또는 폴더의 google_apps_script_sync.gs)를 붙여넣습니다.
  4. 스크립트 상단 DEFAULT_SYNC_TOKEN을 본인만의 비밀번호(예: my-stock-2026!)로 바꾸고 저장합니다.
  5. 우측 상단 [배포] → [새 배포] → 유형: [웹 앱] 선택 후
    • 실행 주체: 나(Me)
    • 액세스 권한: 모든 사용자(Anyone) 로 배포합니다.
  6. 발급된 .../exec URL과 방금 정한 보안 토큰을 PC와 스마트폰의 [⚙ 설정]에 똑같이 입력하고 [저장 & 테스트]를 누르면 끝!
💡 팁: 배포된 URL은 기존 실시간 시세·수급 프록시 URL 칸에도 그대로 넣어서 1개로 겸용할 수 있습니다! (Gemini/OpenDART API 키와 로그인 비밀번호는 보안상 시트에 올라가지 않습니다.)

이 설정은 언제 쓰나요?

PC 서버 없이 스마트폰/웹에서 단독 실행할 때 브라우저 보안(CORS)으로 막히는 실시간 주가·공시·수급 조회(?url=...)를 Google 서버가 대신 읽어다 주는 중계 주소입니다.

기본 프록시 주소가 이미 내장되어 있어 비워두어도 동작하며, 본인이 만든 Google Sheets 동기화 웹 앱 URL(.../exec)을 이 칸에 그대로 붙여넣고 [저장]하면 시세 프록시와 DB 동기화를 1개 주소로 함께 쓸 수 있습니다.

1) PC에서 실행하기

프로젝트 폴더의 run_server.bat을 실행한 뒤 브라우저에서 http://localhost:8000으로 접속합니다. (파일 직접 더블클릭 file://은 동기화 차단될 수 있음)

2) 스마트폰(외출 중 LTE/5G)에서 접속하기
  1. PC에서 업데이트 후 배포용 폴더(deploy/index.html)를 GitHub 저장소에 Add file → Upload files로 덮어쓰기 커밋합니다.
  2. 1~2분 뒤 스마트폰 Chrome에서 GitHub Pages 주소를 새로고침하고, 메뉴 [⋮] → 앱 설치 / 홈 화면에 추가로 앱처럼 실행합니다.
🔄 자동 동기화 팁: PC와 스마트폰 양쪽 모두 [☑ 자동 양방향 동기화]를 켜두면 수정 시 자동 저장(Push), 다른 기기로 돌아오면 화면 복귀 시 자동 불러오기(Pull)가 동작합니다.
